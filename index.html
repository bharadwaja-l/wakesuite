Shared Audit Health

Amazon joins by ASIN. Flipkart joins by FSN. Audit live price becomes the final live price only when the marketplace state is eligible.
Amazon

Suppressed = amazon_has_supersede_issue is True.

Price comparison = suppression False + Buy Now True + valid amazon_selling_price.

Buy Box Suppressed = suppression False + Buy Now False + amazon_edd blank + amazon_deliver_to nonblank.

No OOS/currently-unavailable classification is used.
Flipkart

No suppression status.

Price comparison = Buy Now True + valid flipkart_selling_price.

Buy Now False = No Buy Box. Any scraped Flipkart selling price is ignored because it may belong to another product.
